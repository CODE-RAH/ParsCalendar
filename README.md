## 📝 درباره پروژه

**ParsCalendar** یک تقویم هوشمند دسکتاپ با رابط کاربری گرافیکی است که بر پایه تقویم شمسی (جلالی) کار می‌کند. کاربر می‌تواند تسک‌های روزانه خود را مدیریت کرده، تعطیلات رسمی ایران را مشاهده کند و یادآور خودکار دریافت نماید.

---

## ⚡ ویژگی‌ها

- 📅 **تقویم شمسی کامل** — نمایش ماه‌های شمسی با ناوبری ماه قبل/بعد
- ✅ **مدیریت تسک** — افزودن، مشاهده و تیک‌زدن تسک‌ها برای هر روز
- 🔔 **یادآور خودکار** — نوتیفیکیشن سیستمی برای تسک‌های امروز
- 🔴 **نمایش تعطیلات** — علامت‌گذاری تعطیلات رسمی با رنگ قرمز
- 🌙 **تم تیره / روشن** — قابلیت تغییر تم با یک کلیک
- 💾 **ذخیره خودکار** — تمام تسک‌ها در فایل `tasks.json` ذخیره می‌شوند
- 🔤 **فونت ایران نستعلیق** — پشتیبانی از فونت فارسی اختصاصی

### 🧩 مرحله دوم: نصب Python

آخرین نسخه Python را نصب کرده و این گزینه را فعال کنید:

### 📦 مرحله سوم: نصب پکیج‌ها

bash
pip install PyQt5 jdatetime plyer convertdate

---

### 🔤 مرحله چهارم: نصب فونت (اختیاری)

فایل `IranNastaliq.ttf` را در پوشه‌ای به نام `fonts` در کنار فایل اصلی قرار دهید:


ParsCalendar/
├── main.py
├── fonts/
│   └── IranNastaliq.ttf

> اگر فونت موجود نباشد، برنامه به‌طور خودکار از فونت `Arial` استفاده می‌کند.

bash
python main.py

## 🖥️ راهنمای استفاده

| عملیات | توضیح |
|--------|-------|
| کلیک روی روز | مشاهده و ویرایش تسک‌های آن روز |
| فیلد متن + دکمه افزودن | اضافه کردن تسک به تاریخ امروز |
| تیک‌زدن چک‌باکس | علامت‌گذاری تسک به‌عنوان انجام‌شده |
| کمبوباکس تم | تغییر بین تم تیره و روشن |
| دکمه ماه قبل/بعد | جابجایی بین ماه‌ها |

## 🔔 سیستم یادآور

یادآور به‌صورت **خودکار در پس‌زمینه** اجرا می‌شود و هر ۶۰ ثانیه تاریخ امروز را با لیست تسک‌ها مقایسه می‌کند. در صورت وجود تسک برای امروز، یک **نوتیفیکیشن سیستمی** نمایش داده می‌شود.
